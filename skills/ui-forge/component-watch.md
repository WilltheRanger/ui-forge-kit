## Key

**Status.** **Beats pick**: passes ui-director's fit test better than the current pick (also note it in the project's `components.md`). **Equal**: same job, no gain. **Loses**: fails the fit test (reason in the cell). **Watch**: relevant, no swap now. **Pattern**: reference only, nothing to install. **Changed**: an existing component changed in a way that bears on an earlier decision. **Broke** / **Deprecated**: for components that stop working or are retired.

**Install shorthand.** `@lib/name` is `npx shadcn@latest add @lib/name`. `21st:author/slug` is `npx shadcn@latest add "https://21st.dev/r/author/slug?api_key=$API_KEY_21ST"` (needs `API_KEY_21ST` in the environment; never print the key). A 21st.dev date is the preview timestamp in its asset URL, because `search` ranks components by relevance and can't sort by newest.
